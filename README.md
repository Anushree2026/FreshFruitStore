# Fruit-E-Commerce-

Developed a full-stack fruit e-commerce platform using HTML, CSS, Bootstrap for responsive front-end design, and Node.js for server-side logic.

## Tech Stack
- React
- Vite
- HTML
- CSS
- Bootstrap
- Node.js

## Features
- Product listings
- Shopping cart
- Responsive design
- Order management system

## Run Project

```bash
npm install
npm run dev
