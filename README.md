# Fruit E-Commerce Website

A responsive **fruit e-commerce web application** developed during my Web Development Internship at **RightShift Infotech, Pune**. The application allows users to browse fruit products, manage items in a shopping cart, and access the platform through user authentication.

## Features

* 🍎 Browse and view fruit products
* 🛒 Add and manage products in the shopping cart
* 🔐 User login and signup functionality
* 📱 Responsive user interface
* 📋 Product listing and product details
* ⚙️ Frontend and backend integration
* 🐛 Debugging and resolution of functional issues
* 💬 Order-related functionality

## Technology Stack

| Technology | Purpose                |
| ---------- | ---------------------- |
| HTML5      | Web page structure     |
| CSS3       | Styling and layout     |
| Bootstrap  | Responsive UI design   |
| JavaScript | Frontend functionality |
| Node.js    | Backend development    |

## Key Modules

### Product Listing

Displays available fruit products with relevant information, allowing users to browse and select products.

### Shopping Cart

Users can add products to their cart and manage selected items before placing an order.

### User Authentication

Provides login and signup functionality for users.

### Responsive Design

The application uses **Bootstrap, HTML, and CSS** to provide a responsive interface across different screen sizes.
